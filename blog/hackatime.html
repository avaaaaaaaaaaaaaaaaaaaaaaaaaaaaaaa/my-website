How does Hackatime in VS Code work?

so i got curious how hackatime actually knows how long i've been coding, since there's no timer button or anything. turns out it's not really its own thing. it's hack club running on top of wakatime, which is the tool most editors already use for this. the vscode extension is basically a wakatime plugin, just pointed at hackatime's servers instead of wakatime's.

there's no stopwatch running in the background. instead the extension pings the api every time you do something, switching files, saving, typing for a bit. those pings are called heartbeats, and each one just carries a timestamp, the file name, the project, and the language. nothing scary, no actual code gets sent.

on hackatime's end it takes all those heartbeats and glues them together into sessions. if two heartbeats are within 15 minutes of each other they count as the same coding stretch. stop typing longer than that and it just starts a new one. that's really the whole mechanism, a bunch of tiny pings stitched into hours.

setup is the part that's actually easy. you make an account, grab your api key, and hackatime has a setup page that configures vscode for you, no manually editing config files. install the extension, reload if it asks, and every heartbeat after that just shows up on your dashboard. after that you don't think about it again, you just code and it tracks itself.
